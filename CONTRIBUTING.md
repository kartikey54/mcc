# Contributing

Thanks for looking. This repository holds the public Mission Control client packages (`@missioncontrol/sdk`, `@missioncontrol/mcp`) as they are published.

- Bugs and questions: open an issue with the `x-mcc-request-id` of the request involved when there is one. Never paste an API key; a key starts with `mcc_live_` and anything you paste should be rotated.
- Docs fixes: https://missioncontrol.center/docs/ is the source of truth for behavior. Point to the page you think is wrong.
- Pull requests: keep them small and focused, one change each, with a short description of what and why. By contributing you agree your change is released under the MIT License.
- Security reports: email support@missioncontrol.center rather than opening a public issue.
