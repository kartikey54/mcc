# Mission Control (MCC)

One base URL for every model, with per-request cost, budgets and alerts, run-level traces and exports.

https://missioncontrol.center

## Packages

- `@missioncontrol/sdk`: typed client for the Mission Control API.
- `@missioncontrol/mcp`: MCP server for keys, budgets, usage and the model catalog.

The SDK and MCP packages are coming to this repository.
